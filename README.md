# Module 4 Bonus: Three Layers in Python

This is a small DataMan program. It has three layers. In this bonus you read it, change it, and prove each change stays inside one layer.

Your instructions are on the Canvas page for this bonus. This file is a quick map.

## Files

| File | Layer | Job |
|---|---|---|
| `app.py` | Interface | The only file that uses `input()` and `print()` |
| `dataman/logic.py` | Business logic | The rules |
| `dataman/store.py` | Data | A stand-in for a database |
| `tests/test_logic.py` | | Tests. They use the library only. Do not edit this file. |
| `exercise/` | | Segment 2 exercise |
| `NOTES.md` | | Your answers. Fill each TODO. |
| `check.py` | | Checkpoint check |

## Commands

```sh
pytest -q                 # run the tests
python app.py             # run the program (data in memory)
python app.py --store json
python check.py 1         # after you push Segment 1
python check.py 2         # after you push Segment 2
```

Push after each segment:

```sh
git add -A
git commit -m "Bonus segment 1"
git push
```
